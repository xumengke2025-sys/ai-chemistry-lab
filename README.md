# 拉瓦锡时代实验室

可亲手操作的 3D 化学实验室，参考十八世纪末法国实验室审美，不声称精确历史复原。以近于工作台的视点进入房间；说明、实验选择和记录写在桌上的实体实验本中。纸张受房间光照，随透视和遮挡显示；没有悬浮文本框、常驻指南、目标按钮或背包栏。

## 运行

Node.js 22.12 或更高。首次运行 `npm.cmd install`，然后 `npm.cmd run dev:web`，打开 http://127.0.0.1:5173/ 。当前功能仅需前端服务。

点桌上左侧书堆顶的实验记录本，左页有六个实验，右页有当前步骤、器具素描和最近查看的物件笔记。点击左页的实验名称重新准备该实验；点右页的器具素描走近相关物件；点书页右下角合上。滚轮可拉近纸面阅读。

轻点实物走近，再点一次拿起，随后点实际器材或材料放下。拿起时物件跟随指针，原位置不会留下一件复制品；不可接受的目标使用禁用光标，原因记在实验本中。Escape 放回手中物件、停止倾倒并收起化学图景；双击空白返回。从空白处拖动旋转、滚轮缩放。

也可按住器物直接拖动，杯口、工具、托盘与原位支持吸附，错误位置会退回。触屏采用长按 350 ms 后拖动，尚未完成手机真机验收。

家具与陈设也可直接点击：拉手开合工作台和书桌抽屉、柜门；窗帘横移收拢；书脊抽出或归还藏书；木凳和椅子移开或放回。肖像、收藏瓶、烛台、炉体、织物、研钵研杵与纸笔可走近查看，最近查看的说明写进实验本。指针经过器物时仅有轻微材质反射和光标变化。收藏天平的砝码可提起归位，蒸馏器玻璃头与接收瓶可移开查看，钟罩塞可拔出装回。这些结构操作独立于化学库存；当前未模拟蒸馏。

2026-10-12 扩大工作室主空间至约 16.6×18.2 米、高 6.6 米，增加真实拱门收藏侧廊和后部书写区。灰泥檐口、柱饰、木护墙、高窗与庭园剪影形成十八世纪工作室氛围；低视点、前后陈设和斜向窗光建立纵深。侧廊藏书与后桌仍可直接操作，说明保留在实体实验本中。竖屏初始取景对准实验台；仍需转动画面查看两侧。

## 亲手实验

从实体记录本选择实验恢复器材和库存。实验不会自动投料。

- 药剂：轻点瓶身走近，直接点木塞开瓶；再点瓶身拿起，点反应杯放到杯口。瓶子由黄铜架支承。按住瓶身向右拖，倾角与时间决定剂量，松手即停；原有向上拖也支持。定量取液用量取器皿点已开塞来源取 10 mL，滴管取 0.5 mL，再拿起装液工具点杯口加入。
- 金属：把镊子拖到铁、铜或锌，夹取 0.140 g；再拖到杯口投入。空镊子拖到杯中可取回剩余金属与沉积铜，再放到铁钉前方的金属回收托盘。
- 粉末：药匙拖到碳酸钠罐取 0.100 g；可先拖到小称量托盘读数，再拖到杯口。加水后溶解。
- 集气与密闭：导管拖到杯口收集后续气体；密闭塞与导管互斥。密闭页的锌先存于杯内干燥隔室，加酸、称量、塞紧后点击玻璃棒才开始内部混合。把杯子拖到小称量托盘复称；把塞子拖回原位可观察逸气造成的称量下降。
- 炉具：杯子拖到炉台；直接点炉门开火或关火。温度向 60 或 20 °C 缓慢变化，仅作教学演示。
- 观察：直接点观察镜展开或收起粒子示意；拖动粒子区旋转、滚轮缩放。方程式和读数写进实验本。宏观沉积、颜色、气体和微观示意读取同一实验状态。
- 清理：杯子拖到残液收集罐倒空，再拖到陶盆洗净。残液与回收金属保留在总量记录中。实验本页签可以重新开始实验。

六个实验：铁与硫酸铜、酸碱中和、碳酸盐与酸、氢氧化铜沉淀、锌与稀酸、密闭质量守恒。自动本地快照约每 3 秒保存，刷新恢复材料、库存和装配；损坏或不守恒的快照会被拒绝。浏览器禁用存储时仍可使用当前实验。

`npm.cmd test` 运行科学计量与操作事务测试，`npm.cmd run build` 包含 TypeScript 检查；`dist/` 是静态构建结果。`npm.cmd run preview` 可预览生产版本，默认 http://127.0.0.1:4173/ 。实验不依赖后端或 API 密钥。

## 工程

React 19、TypeScript、Vite、Three.js、React Three Fiber、Drei、Zustand。`src/lab/` 为独立科学计算、物件注册表、库存与操作事务；`src/scene/` 为模型、房间、镜头和交互。`public/textures/` 是公开 PBR 贴图，`public/art/` 是公开肖像，`verification/` 保存验收证据。

初始工程中保留了 Fastify 后端及 OpenAI SDK 配置模板；当前场景不使用 AI 接口，也未连接 Hyper3D。
