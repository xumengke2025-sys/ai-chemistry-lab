# 化学教学模型与资料

日期：2026-10-09。本项目是历史风格的现代化学教学空间。单位：物质的量 mol、体积 mL、质量 g、温度 °C。

## 有限规则库

| 操作 | 规则 | 限量关系 |
| --- | --- | --- |
| 铁与硫酸铜 | Fe + Cu²⁺ → Fe²⁺ + Cu | min(nFe, nCu²⁺) |
| 酸碱中和 | H⁺ + OH⁻ → H₂O | min(nH⁺, nOH⁻) |
| 碳酸盐与酸 | CO₃²⁻ + 2H⁺ → CO₂ + H₂O | min(nCO₃²⁻, nH⁺/2) |
| 氢氧化铜沉淀 | Cu²⁺ + 2OH⁻ → Cu(OH)₂ | min(nCu²⁺, nOH⁻/2) |
| 锌与酸 | Zn + 2H⁺ → Zn²⁺ + H₂ | min(nZn, nH⁺/2) |
| 碳酸钠溶解 | Na₂CO₃(s) → 2Na⁺ + CO₃²⁻ | 有液体时按固体量解离 |
| 密闭质量守恒 | 密闭隔室中的锌与酸在内部混合 | 质量包含杯、液体、固体和留存气体 |

反应步长 0.05 s；教学反应速率上限 0.0004 mol/s。这是为了可观察而设定的动画时间，不是实验动力学数据。页面失焦或设备变慢可以使观看变慢，最终计量不变。多个已定义反应同时满足时按代码规则顺序推进，不代表任意混合体系的平衡预测。

液体来源均采用 0.100 mol/L（指示剂与水除外）；固体夹取 0.140 g，药匙 0.100 g，量取器皿 10 mL，滴管 0.5 mL。这些是产品的起始配置，不是史料或测试结果。杯容量 100 mL，转移受库存与容量共同限制。

## 近似与边界

- 采用理想稀溶液及约 1 g/mL 的溶液密度，溶剂水质量扣除所含溶质。质量以原子质量的同一套数值计算；反应自身守恒，但不预测真实溶液体积收缩或固体占容积。
- 酚酞采用 pH > 8.2 的简化颜色阈值，不用颜色代替中和程度。pH 仅对当前强酸强碱体系按过量离子和体积估算；金属离子水解、碳酸盐缓冲、活度、溶度积和弱酸平衡不计算，这些混合体系不显示 pH。
- 铜离子蓝色、亚铁淡绿、铜沉积、蓝色氢氧化铜与气泡是示意。沉淀与溶液分别存储；离子在微观层独立显示，不画成完整的溶解盐分子。
- 开口气体记入 escaped；连接导管后的新生气体记入 collected；密闭气体记入 gas。打开密闭塞时气体按当前路径转出，原有逸散量不追溯收入集气瓶。模型不计算真实气体压力、溶解度或水上集气损失。
- 炉具温度为朝 20 或 60 °C 的一阶教学变化，20 s 时间常数；不参与反应计量或真实热力学预测。本库没有燃烧反应。
- 未定义的组合不模拟现象；例如铁与酸不在当前展示库。所有 UI 与说明必须明确“已定义的反应”，不声称未出现动画就意味着现实中没有反应。
- 微观粒子按教学比例，轨迹只作示意；自由旋转不会改变实验，介绍的结构视图不改变装配。
- 清洗先倒入残液收集罐；废液与取回固体仍记入世界总量。记录本重置是明确重开实验，不是物质转移。保存恢复会校验初始库存对应的元素总量、非负量、容量和装配关系。
